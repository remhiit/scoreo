# Guide de l'utilisateur

Scoreo garde les scores de vos parties entre amis : qui a joué, à quoi, qui a gagné, et ce que
ça donne sur la durée (classement, face-à-face, trophées). Tout reste sur votre appareil ; une
sauvegarde sur Google Drive est possible si vous le souhaitez.

Ce guide décrit l'application telle qu'elle se présente au joueur, écran par écran.

## Bon à savoir

- **Vos données restent chez vous.** Joueurs, jeux et parties sont enregistrés dans le navigateur de
  l'appareil, sans compte ni serveur. Vider les données du site efface tout ; la
  [synchronisation Google Drive](synchronisation.md) est la manière de s'en prémunir.
- **Rien n'est jamais réécrit dans votre dos.** Supprimer un joueur garde ses parties ; archiver un
  jeu garde son historique. Seules la fusion de doublons, le nettoyage des joueurs inactifs et la
  suppression d'une partie effacent définitivement quelque chose, et toujours après confirmation.
