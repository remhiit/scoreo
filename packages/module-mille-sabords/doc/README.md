# Documentation — 1000 Sabords

Le jeu de dés **1000 Sabords**, compté par ce module dans Scoreo.

> `technique/` décrit encore l'application Kotlin dont ce module est le portage — celle qui ne vit
> plus que comme oracle de test dans `legacy/1ksabord-kotlin/`. Sa réécriture pour le module
> TypeScript est l'objet de l'issue #354. La doc du **domaine** (`technique/domaine/`), elle, reste
> vraie : le portage est vérifié contre l'oracle par un test différentiel golden.
