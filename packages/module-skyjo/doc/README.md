How the module works is read in its code (`src/`, types and JSDoc included); a decision the code
cannot tell is an ADR in the workspace's [`doc/adr/`](../../../doc/adr/README.md). The backlog, the
automation pipeline and everything else that belongs to the repository as a whole are documented in
the workspace's `doc/` — this directory is the game's.
