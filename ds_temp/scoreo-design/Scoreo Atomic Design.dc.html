Scoreo design system

Scoreo — atomic design systemScoreo — design system atomique

The same screens we built, decomposed into Brad Frost's five layers: tokens feed atoms, atoms compose into molecules, molecules into organisms, organisms fill templates, and templates become the real pages. Every piece below is the live component, not a picture of one — Button, Input and Modal come from the design system bundle; the rest is built on its tokens.Les mêmes écrans, décomposés selon les cinq niveaux de Brad Frost : les tokens nourrissent les atomes, les atomes composent les molécules, les molécules les organismes, les organismes remplissent les gabarits, et les gabarits deviennent les pages réelles. Chaque élément ci-dessous est le composant vivant, pas une image — Bouton, Champ et Modale viennent du bundle du design system ; le reste est bâti sur ses tokens.

The only two states the app produces: a duplicate name, and a field locked while a sync runs. Errors read as one plain sentence under the field, never as a toast. Upstream has no invalid state — invalid + error are the app's extension, listed in EXTENSIONS.md; until the system adopts them the red border is set by the caller, as here.Les deux seuls états que l'appli produit : un nom en double, et un champ verrouillé pendant une synchro. Le système amont n'a pas d'état invalide — invalid et error sont une extension de l'appli, listée dans EXTENSIONS.md ; en attendant son adoption, la bordure rouge est posée par l'appelant, comme ici.
